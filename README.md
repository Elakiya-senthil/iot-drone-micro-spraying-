# IoT-Enabled Agricultural Drone for Fertilizer & Pesticide Micro-Spraying

## Project Overview
An IoT-based agricultural drone system designed for precision micro-spraying of fertilizers and pesticides. This repository contains the Python control and safety logic that monitors tank liquid levels to prevent pump dry-running and ensure efficient spraying.

## Key Features
- **Tank Level Monitoring:** Checks real-time fertilizer/pesticide levels (0–100%).
- **Dry-Run Protection:** Automatically halts spraying readiness and triggers a refill alert if the tank level drops to 20% or below.
- **Precision Micro-Spraying:** Ensures optimal chemical usage and protects spray nozzles from air-locks.

## Tech Stack
- **Language:** Python
- **Domain:** IoT, Smart Agriculture, Embedded Logic
